# Not the Same Protector: Deployment-Dependent Protective Intervention in LLMs

NeurIPS 2026 Workshop RTCA submission.

Full response logs and coding results for the study. Four models across three deployment conditions (voice UI, text UI, raw voice API), 30 responses per cell, each response coded along five binary protective indicators (MED, FA, EM, USP, SC).

## Data availability

Voice recordings are not released, as they constitute identifiable data. Only anonymized transcripts and coded annotations are shared.

## Anonymity

This repository is anonymized for double-blind review.
